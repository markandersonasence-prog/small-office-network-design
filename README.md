# Small Office Network Design

A Cisco Packet Tracer project demonstrating the design and configuration of a small-office network.

## Project Overview

Designed and configured a small-office network using Cisco Packet Tracer, implementing VLANs 10/20/30, DHCP, IP addressing, inter-VLAN routing, and switch security with password protection and credential encryption.

## Network Devices

- Router
- Cisco Switch
- Access Point
- Desktop
- Laptop
- Smartphone
- Network Printer

## Network Configuration

- VLAN 10
- VLAN 20
- VLAN 30
- DHCP
- IP Addressing
- Inter-VLAN Routing
- Switch Security
- Password Protection
- Credential Encryption
- Connectivity Testing and Troubleshooting
